Privacy Policy

darami-youtube-tool (DARAMI STUDIO) — last updated 17 November 2026

Who uses this tool

darami-youtube-tool is used only by the owner of the DARAMI STUDIO YouTube channel, on the owner's own computer, for the owner's own channel. It has no other users.

What it accesses

With the channel owner's permission (Google sign-in), the tool uses YouTube API Services to:

  • upload the channel's own videos, thumbnails and captions, and edit their titles, descriptions, playlists and publishing times;
  • read and moderate comments on the channel's own videos;
  • read the channel's own analytics and reports (views, watch time, audience retention, impressions).

It does not access any other person's account or channel.

How data is stored

The sign-in token is stored only on the channel owner's computer, outside any shared folder. Analytics numbers are saved as files on the same computer to track the channel's own performance. Nothing is sold, shared with third parties, or used for advertising.

Removing access

The owner can remove the tool's access at any time from the Google Account security page: myaccount.google.com/permissions. Deleting the token file on the computer also stops all access.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Contact

Questions: through the DARAMI STUDIO channel page, youtube.com/@darami.studio.
